# Vocab Trainer

A command-line vocabulary trainer for English learners. Each word is saved
with an example sentence, and words come back for review just before you're
likely to forget them (spaced repetition with Leitner boxes).

**Status:** work in progress. Version 1 is being built.

## Requirements

- Python 3.13 or newer
- [uv](https://docs.astral.sh/uv/)

## Run it

```
uv run vocab-trainer
```

## Run the tests

```
uv run pytest
```
